# 虚拟环境配置

* Ubuntu 20.04
* CUDA 11.8



## Install

```cmd
git clone https://github.com/River-Zhang/SIFU.git
# 镜像下载 ： git clone https://mirror.ghproxy.com/https://github.com/River-Zhang/SIFU.git

sudo apt-get install libeigen3-dev ffmpeg

# cd -> SIFU
conda env create -f environment.yaml

conda activate sifu

# 降级pip
pip install pip==23.0

# 优先安装Requeirements.txt的四个Git项目
pip install git+https://github.com/facebookresearch/pytorch3d.git@v0.7.2

pip install git+https://ghproxy.net/https://github.com/NVIDIAGameWorks/kaolin.git

pip install git+https://ghproxy.net/https://github.com/YuliangXiu/rembg.git

pip install git+https://ghproxy.net/https://github.com/YuliangXiu/neural_voxelization_layer.git
## 若无法正常下载，clone到服务器上再使用 pip install . 进行安装

# requirements.txt有以下[1]变动
## PyMCubes --> PyMCubes==0.1.2
pip install -r requirements.txt


################
# 以下是SMPL配置
################
# 官方版本
## 去Github自己看

# 非官方版本[推荐]

```



将[pre-trained model](https://drive.usercontent.google.com/download?id=13rNSmQI_VaMtwlMBSUaxEGybzJEl5KTi&export=download&authuser=0&confirm=t&uuid=713f0fff-5d52-4be9-8498-4f69324b1f5a&at=AO7h07fqd4kFIDWIxw2LKs1-4pG7%3A1725969762996)放入 `SIFU/data/ckpt/`

将[u2net](https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2net.onnx)放入 `/root/.u2net/` 

将[pose_landmark_heavy](https://storage.googleapis.com/mediapipe-assets/pose_landmark_heavy.tflite)放入 `/opt/conda/envs/sifu/lib/python3.8/site-packages/mediapipe/modules/pose_landmark/`
